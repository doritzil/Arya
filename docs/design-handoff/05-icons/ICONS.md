# Icons

All icons are **Phosphor Icons** (MIT licence — https://phosphoricons.com, Swift package: https://github.com/phosphor-icons/swift).

Weights: **duotone** by default (tint layer = 20% of the icon colour; **peach at 55%** inside icon tiles, active tabs, player side controls and pressed icon buttons). **Fill** for play / pause / next / record, the selected tab and a pressed heart. **Bold** for the simple glyphs listed below. SVGs for every icon in all three weights are in `svg/`.
